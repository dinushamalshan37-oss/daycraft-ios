📱 DayCraft
An offline-first daily planner and focus tracker for iPhone, built with SwiftUI.

DayCraft is an iOS app project concept that combines task planning, focus sessions, and habit streaks in one calm interface. The goal is to build a polished native mobile app while learning modern Apple development patterns.
Status: Planned project — the features below are not yet implemented.

✨ Planned Features
- [ ] Add, edit, complete, and organize daily tasks
- [ ] Run configurable Pomodoro-style focus sessions
- [ ] Track habit completion and daily streaks
- [ ] Save data locally for offline use
- [ ] Show a weekly progress summary
- [ ] Schedule optional local reminders
- [ ] Support light and dark appearance

🚀 Getting Started (After Implementation)
1. Install Xcode on a Mac.
2. Clone the repository once the app source is published.
3. Open DayCraft.xcodeproj (or the Xcode project included in the repository).
4. Choose an iOS 17+ simulator or supported iPhone.
5. Build and run the app from Xcode.
🗺️ Development Roadmap
Phase 1: Task list, navigation, and SwiftData persistence.
Phase 2: Focus timer, habits, and daily streaks.
Phase 3: Notifications, accessibility, testing, and UI polish.
🎯 Learning Goals
Swift language fundamentals, SwiftUI layouts, app state management, SwiftData, local notifications, accessibility, and iOS app lifecycle.
